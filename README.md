# GISFORUS Spatial Research Suite

Publication-grade satellite analysis on your own Google Earth Engine — no code.
LULC classification (Random Forest / CART / SVM) with accuracy and change detection,
40+ cloud-analysis layers, and a drag-and-drop Publication Studio for print-ready
figures. Ships as a desktop app for macOS and Windows with a bundled R + Python runtime.

## Download

Get the latest macOS (`.dmg`) and Windows (`.exe`) builds from the
**[Releases page](https://github.com/anant9677/spatial-research-suite-public/releases/latest)**.
Each installer bundles its own R + Python runtime — nothing else to install. The app runs
on your own Earth Engine account and quota; your imagery, boundaries and analysis stay on
your machine (GEE compute is locked to localhost in the packaged build).

## Exports (Free / Basic / Pro)

Everything collects in the in-app **Export Manager**, then downloads by plan:

- **Free** — boundary exports (Shapefile / GeoJSON / KML)
- **Basic (₹299/mo)** — data tables & reports (CSV, Excel, HTML)
- **Pro (₹799/mo)** — figures, maps, galleries, rasters (GeoTIFF), Publication Studio
  layouts, the PDF summary report, and the full "download all" bundle
